# POUFFE — независимый демонстрационный сайт мебельной мастерской

Готовый **статический сайт** без Node.js, npm, сервера и сборки. HTML + CSS + JavaScript + 19 самостоятельных SVG-файлов.

## Что внутри

- `index.html` — полноценная одностраничная витрина.
- `styles.css` — дизайн, адаптивность, эффекты, анимации и режим reduced motion.
- `script.js` — фильтры проектов, модальное окно, сравнение условных кресел, смена тканей, конфигуратор и копирование текста, фото только в памяти браузера.
- `config.js` — контакты, четыре опубликованных примера проектов, услуги и контент. Меняйте этот файл для адаптации.
- `assets/*.svg` — оригинальные векторные сцены, НЕ реальные фотографии работ POUFFE.
- `robots.txt` и `vercel.json` — запрет индексации демонстрации.

## Как открыть локально

Откройте `index.html` в браузере. Для более корректной проверки на локальном сервере:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080/`.

Файл `POUFFE_preview.html` (идёт отдельно от ZIP) содержит ресурсы внутри и открывается без соседних файлов.

## Vercel

1. Создайте GitHub-репозиторий `pouffe-website`, загрузите содержимое папки **в корень** репозитория.
2. В Vercel выберите **Add New Project** и импортируйте репозиторий.
3. Framework Preset: **Other**, Root Directory: `./`, Build Command: **не требуется**, Output Directory: **не указывать**.
4. Предлагаемое имя проекта: `pouffe-demo`, домен: `pouffe-demo.vercel.app`, **если свободен**.

Статические файлы должны лежать именно в корне репозитория: `index.html`, `config.js`, `styles.css`, `script.js`, папка `assets`.

## Важно о демонстрации

- Это **неофициальный концепт**. Компания не заказывала проект и не связана с демодоменом.
- Четыре цены взяты из отдельных опубликованных **примеров работ**, не являются прейскурантом. Источник: https://uslugi.yandex.ru/profile/Pouffe-467241
- Иллюстрации мебели и условная пара «до/после» созданы для демо и **не представляют реальные проекты** мастерской.
- Фотографии, выбранные в конфигураторе, только отображаются локально через `URL.createObjectURL` и **никуда не отправляются**. Копируемый текст не включает изображения.
- Отправка реальных заявок отключена. Нет аналитики, трекеров и серверной обработки данных.
